# Moquegua Soft

Sitio web y mini ERP/CMS de Moquegua Soft.

Todo el código vive en [`server/`](server/): una aplicación Node.js (Express + EJS + SQLite) que sirve el sitio público y el panel de administración (`/admin`) desde donde se gestionan los textos e imágenes del sitio (CMS) y los clientes, proyectos, ingresos, gastos y comprobantes del negocio (ERP).

Para instalar, ejecutar en local o desplegar en el VPS, sigue [`server/README.md`](server/README.md).
